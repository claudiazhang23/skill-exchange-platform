# 换技 Web MVP

这是一个面向线上技能互换的可交互网页 MVP。它只保留两种交易方式：技能币和直接互换；默认工作台围绕发现匹配、聊天沟通与预约展开。

## 本地预览

在此目录运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 已实现的前端交互

- 按互换、技能币筛选，或按关键词搜索技能和伙伴
- 查看匹配详情，选择交易方式和可约时段，发出模拟约课请求
- 从详情页进入聊天，发送本地模拟消息
- 发布可教技能，查看技能钱包、约课与信用状态
- 自适应桌面和移动端布局

## 上线时建议接入

1. 身份认证、用户档案、技能标签和信用评分服务。
2. 用匹配服务计算技能互补度、兴趣相近度、可约时段与响应率。
3. 实时聊天、日历空闲查询、预约状态机和提醒通知。
4. 技能币账本、预约完成确认和争议处理机制。
5. 内容审核、举报处理与隐私设置。
