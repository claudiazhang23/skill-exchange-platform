# 换技 - 全栈技能交换平台

一个可运行的线上技能互换平台。前端、Node.js API、SQLite 数据库和账号会话都在同一个项目中；技能、匹配、聊天、预约、技能币、评价和信用分不再只保存在浏览器里。

## 已实现的闭环

1. 账号注册、登录、登出和 HttpOnly 会话 Cookie。
2. 可教技能与学习目标的发布、编辑、下架，以及个人资料和可约时间维护。
3. 服务端匹配：根据技能互补、学习目标、可用交换方式与双方共同可约时间计算推荐。
4. 真实双账号流程：一方发起技能互换或技能币约课，另一方在自己的账号内接受或婉拒。
5. 预约状态机：待确认、已确认、改期待确认、进行中、双方确认完成、取消和拒绝。
6. 双方完成确认：授课方开课，双方分别确认课程结束；双向互换必须完成两节课才会结算。
7. 技能币账本：发起技能币约课时锁定；取消/拒绝时退款；完成后结算给授课方。完成双向互换后，双方获得守约奖励。
8. 双向聊天、未读消息、站内通知、完成后互评和信用分更新。

## 快速启动

需要 Node.js 24 或更高版本，因为项目使用内置 `node:sqlite`，不需要安装额外依赖。

```bash
npm start
```

打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)。首次运行会在 `data/huanji.db` 创建 SQLite 数据库和演示账号。

## 测试

```bash
npm test
```

集成测试从临时空数据库启动服务，验证以下真实 HTTP 流程：登录、服务端匹配、技能币锁定、跨账号接受、授课方开课、双方完成确认、结算、互评、双向互换奖励、取消退款、跨账号消息、资料与技能卡更新。

## 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `3000` | HTTP 服务端口 |
| `DATABASE_PATH` | `./data/huanji.db` | SQLite 数据库文件位置 |
| `NODE_ENV` | 未设置 | 设为 `production` 时会为会话 Cookie 启用 `Secure` |

## 部署

这是一个需要持久化磁盘的 Node 服务，不应部署到 GitHub Pages。可使用任意支持 Node 24 和持久卷的平台，或用项目中的 Dockerfile：

```bash
docker build -t huanji .
docker run -p 3000:3000 -v "$(pwd)/data:/app/data" huanji
```

生产环境至少应设置持久化卷、HTTPS 反向代理和定期数据库备份。真实视频会议、邮件/短信提醒和身份核验可通过外部服务接入，但不会影响当前账号、预约和账本闭环。
