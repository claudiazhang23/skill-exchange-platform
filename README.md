# 换技 - 技能交换平台

一个无需后端即可完整演示的线上技能互换 MVP。数据保存在浏览器 `localStorage`，刷新页面后仍会保留当前的技能、聊天、约课、技能币和评价状态。

## 可以完整走通的流程

1. 编辑个人资料，发布、修改或下架“我能教”和“我想学”的技能卡。
2. 系统根据技能互补、学习目标和可约时间计算匹配度；可搜索、筛选技能币或直接互换的搭档。
3. 和匹配对象聊天，选互换方式、学习时段和回馈技能，发出约课请求。
4. 请求会进入“我的约课”；演示版会模拟对方确认。也可以处理进入站内的互换邀请。
5. 已确认约课支持改期、取消。技能币约课会在发起时锁定，取消时自动退回。
6. 开始线上约课并确认完成；双向互换需要双方课程都完成，随后会获得守约奖励。
7. 完成后提交评价，信用分、评价记录、通知和技能钱包会同步更新。

## 本地运行

不需要安装依赖。在项目目录执行：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 数据与重置

- 所有演示数据仅保存在当前浏览器的本地存储中。
- 在“我的技能档案”点击“重置演示数据”，可以恢复首次体验的样例数据。
- 不涉及充值、支付或购买；技能币只在预约、退款、守约奖励与结算中流动。

## GitHub Pages 部署

这个项目是纯静态站点。进入 GitHub 仓库的 `Settings` → `Pages`，选择：

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/(root)`

保存后，GitHub 会提供公开的演示链接。

## 生产上线前需要替换的部分

当前版本将完整交互闭环在单浏览器演示数据中。多用户生产版需要接入以下服务：

1. 身份认证、用户资料、技能标签与内容审核。
2. 数据库和后端状态机，确保预约、取消、结算和争议处理具有一致性。
3. 实时聊天、通知、日历空闲查询与会议链接服务。
4. 防刷与信用机制，包括确认完成、投诉、申诉和互评规则。
5. 隐私、安全、数据导出与删除机制。

## 验证

运行状态机测试：

```bash
node tests/state-machine.test.mjs
```

该测试覆盖匹配、技能币预约、互换确认、课程完成、评价、锁定技能币退款与结算。
